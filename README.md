# Upstate Homebrew tap

Official binary distribution for [Upstate](https://upstate.run).

```sh
brew install upstate-run/tap/upstate
upstate version
```

macOS and Linux, Intel/AMD and ARM64. Versioned archives and SHA-256 checksums
are published in [cli-releases](https://github.com/upstate-run/cli-releases/releases).
No source checkout or Go compiler is required. To verify the installed binary:

```sh
brew test upstate-run/tap/upstate
```
